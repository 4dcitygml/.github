# Governance

4dcitygml is currently maintainer-led. Public issues and pull requests are the
normal place for proposals, evidence, review, and decision records.

## Responsibilities

- Contributors propose scoped changes and publish the evidence they are allowed to share.
- Reviewers evaluate technical, semantic, provenance, privacy, and licensing effects.
- Repository maintainers define required checks, approve changes, and protect releases.
- Each city-data repository retains its own source attribution and final data-review authority.

## Decisions

Routine changes are decided through review in the owning repository. Changes to
stable identifiers, provenance rules, supported standards, security boundaries,
or cross-repository interfaces require an issue and a written rationale before
implementation. Maintainers seek practical consensus but retain responsibility
for the final repository decision and may defer changes that cannot yet be operated safely.

Project roles may expand as sustained contributors emerge. Permissions are
granted narrowly and reviewed when responsibilities change.
