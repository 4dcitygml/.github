# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose users,
credentials, repositories, or data. Use GitHub's
[private vulnerability reporting](https://github.com/4dcitygml/.github/security/advisories/new) (also available in every 4dcitygml
repository under Security → Report a vulnerability) and include:

- the affected repository, version, commit, or release;
- the observed and expected behavior;
- minimal reproduction steps or a proof of concept;
- the potential impact; and
- a safe way to contact you, if you want a reply.

Do not send live credentials, personal data, or unnecessary copies of private
repositories. Use synthetic examples wherever possible.

## Supported versions

Until repository-specific policies state otherwise, security fixes target the
latest published release and the default branch. Older releases may not receive
backports.

We will acknowledge reports and coordinate remediation as capacity permits.
Please allow a reasonable period for investigation before public disclosure.
This project does not currently operate a paid bug-bounty program.
