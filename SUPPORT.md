# Support

For reproducible questions, bug reports, and feature requests, open an issue in
the repository that owns the relevant code or data:

- tools and local applications: `4dcitygml/tools`
- reusable repository setup: `4dcitygml/city-template`
- building or source-data questions: the relevant city repository
- portal content: `4dcitygml/4dcitygml.github.io`

Include the operating system, tool version or commit, city repository, relevant
building ID, expected result, and a minimal reproduction when applicable.

For security vulnerabilities, privacy concerns, or a request to remove sensitive
material, use the [private report form](https://github.com/4dcitygml/.github/security/advisories/new) instead of a public issue. The form is
GitHub's private vulnerability reporting; only maintainers can read it, and we accept
non-security reports there too. The project has no public email address. Support is provided
on a best-effort basis; response times are not guaranteed.
